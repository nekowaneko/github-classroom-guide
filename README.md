## 你們的工作區在哪裡

你們每一組有一個 **Google Drive 共用資料夾**，過程中產生的所有檔案都放在那裡。
資料夾連結請看 Classroom，或打開你 Google 雲端硬碟左邊的「**與我共用**」。

之所以要用共用資料夾，而不是把檔案放在某一個人的電腦裡，是因為可以避免

1. 負責處理數據處理的組員沒來，又搞失蹤，導致整週沒進度。
2. 放在電腦上的資料被其他人刪光光(沒錯，有人做過)。

檔案如果被誤刪或改壞，可以在 Google Drive 上按右鍵，用「**版本紀錄**」把舊的版本救回來。

## 檔案取名格式
